Interlock · Experiment E4실험 E4

Needless refusals on real commit histories실제 커밋 기록에서 불필요한 차단

A coordination layer for AI coding agents is only useful if it blocks real conflicts and lets everything else through. E4 measures the second part on real code. AI 코딩 에이전트 조정 도구는 진짜 충돌만 막고 나머지는 통과시켜야 쓸모가 있습니다. E4는 그 두 번째를 실제 코드로 측정했습니다.

Run on 2026-10-18 with Interlock V3.0.0.2026-10-18, Interlock V3.0.0으로 실행. Raw results (JSON)원자료 (JSON)

Method방법

  • Source: the commit histories of five public repositories: httpx, click, requests (Python) and zod, ky (TypeScript).대상: 공개 저장소 5개의 커밋 기록. httpx, click, requests(Python), zod, ky(TypeScript).
  • Pairs: two consecutive commits that change the same file are replayed as two agents starting at the same time from the first commit's parent. Up to 1,500 pairs per repository; 438 pairs that could not be replayed were skipped.쌍: 같은 파일을 연달아 고친 두 커밋을, 앞 커밋의 부모에서 동시에 출발한 두 에이전트의 작업으로 재현했습니다. 저장소당 최대 1,500쌍, 재현할 수 없는 438쌍은 제외했습니다.
  • Ground truth is git itself: independent pairs are merged with real git merge (merge-ort, via git merge-tree). All 3,535 independent pairs merged without conflict, so any refusal of them is needless. Pairs where the second commit was built on the first (1,817) cannot be replayed as concurrent work and are counted as conflicts, an approximation.정답은 git: 독립 쌍은 실제 git merge(merge-ort, git merge-tree)로 합쳤고, 3,535쌍 모두 충돌 없이 합쳐졌습니다. 따라서 이 쌍을 막으면 불필요한 차단입니다. 뒤 커밋이 앞 커밋 위에서 만들어진 1,817쌍은 동시 작업으로 재현할 수 없어 충돌로 분류했습니다(근사치).
  • Rules compared: a file lock (one agent per file); a symbol lock (Interlock V2: refuse when changed functions or classes overlap); and the Interlock V3 line rule (refuse when the second change would make a merge conflict with the first one's changed lines).비교한 규칙: 파일 잠금(파일당 에이전트 하나), 심볼 잠금(Interlock V2: 바뀐 함수·클래스가 겹치면 차단), Interlock V3 줄 규칙(뒤 변경이 앞 변경의 줄과 머지 충돌을 일으킬 때만 차단).

Limits한계

  • This is a replay of commit histories, not agents writing code. Our other experiments, with 373 live Claude Code sessions, are not included here.에이전트가 직접 코드를 쓴 것이 아니라 커밋 기록을 재현한 실험입니다. 실제 Claude Code 세션 373개로 진행한 나머지 실험은 여기에 포함하지 않았습니다.
  • Pairs counted as conflicts were not merged, so the "missed" column is approximate.충돌로 분류한 쌍은 실제로 합치지 않았으므로 "놓침" 수치는 근사치입니다.
  • The Interlock source and the experiment harness are not public.Interlock 소스와 실험 도구는 공개하지 않습니다.
