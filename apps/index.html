Interlock

Working demo데모 작동 중

Run many AI coding agents on one codebase without them overwriting each other. Interlock tracks which code each agent is changing — down to the function — and enforces it at three layers: the edit, the commit and the merge. Every verdict comes with its evidence. 여러 AI 코딩 에이전트가 하나의 코드베이스에서 서로의 작업을 덮어쓰지 않게 해줍니다. 각 에이전트가 어떤 코드를 바꾸는지 함수 단위까지 추적하고, 편집 · 커밋 · 머지 세 단계에서 막습니다. 모든 판단에는 근거가 함께 나옵니다.

  • Symbol-level claims함수 단위 점유
  • Dependency cautions & contract-change notices의존 관계 경고 · 시그니처 변경 알림
  • Edit, commit & merge enforcement편집 · 커밋 · 머지 단계 차단
  • Fair queue with deadlock detection대기열 · 교착 감지
  • Leases tied to session liveness세션이 끝나면 자동 해제
  • Works with Claude Code, Codex & CursorClaude Code · Codex · Cursor 지원

In development개발 중

  • Price ranges with the evidence shown근거와 함께 보여주는 가격 범위
  • Optional 3D scan to narrow the range원하면 3D 정밀 분석으로 범위를 좁히기
  • Buyers can check whether an asking price is fair구매자는 호가가 적정한지 확인 가능
