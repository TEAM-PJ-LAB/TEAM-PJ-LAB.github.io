Set up the login로그인 설정

  1. Create aGitHub에서 fine-grained token세분화된 토큰(fine-grained): Resource owner TEAM-PJ-LAB, Only select repositories → TEAM-PJ-LAB.github.io, Contents Read and write.을 만듭니다 — Resource owner TEAM-PJ-LAB, Only select repositories → TEAM-PJ-LAB.github.io, Contents Read and write.
  2. If the organization asks for approval, an owner approves it in the organization settings.조직 승인 요청이 뜨면 조직 소유자가 조직 설정에서 승인합니다.
  3. Paste it below and choose the ID and password. The token is encrypted in this browser and only the encrypted copy is saved to the site.아래에 붙여 넣고 아이디·비밀번호를 정합니다. 토큰은 이 브라우저에서 암호화되고, 사이트에는 암호화된 값만 저장됩니다.

The encrypted copy is public, so a short password can be guessed offline. Use 12+ characters.암호화된 값은 공개되므로 짧은 비밀번호는 오프라인에서 맞춰질 수 있습니다. 12자 이상을 쓰세요.
