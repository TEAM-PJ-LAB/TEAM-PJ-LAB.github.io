Main project메인 프로젝트

Interlock

Run many AI coding agents on one codebase — without them overwriting each other. 여러 AI 코딩 에이전트가 하나의 코드베이스에서, 서로의 작업을 덮어쓰지 않게.

Claude Code, Codex and Cursor are good enough to run in parallel — but they don't notice each other. Interlock is the signal box for your agents: it knows what every agent is changing, never lets two changes collide, and explains every decision. Claude Code, Codex, Cursor는 이제 동시에 돌릴 만큼 뛰어나지만, 서로를 알아채지 못합니다. Interlock은 에이전트들의 신호소입니다. 누가 어떤 코드를 바꾸는지 알고, 두 변경이 부딪히지 않게 막으며, 모든 판단의 근거를 보여줍니다.

How it works자세히 보기 Demo repo데모 저장소 ↗
  • Symbol-level claims함수 단위 점유Two agents can work in the same file, on different functions.같은 파일이라도 다른 함수라면 두 에이전트가 동시에 작업합니다.
  • Stops agents that never ask묻지 않는 에이전트도 차단Edit hooks for Claude Code, Codex and Cursor, a git pre-commit hook, and a GitHub merge check.Claude Code·Codex·Cursor 편집 훅, git 커밋 훅, GitHub 머지 체크.
  • No deadlocks, no stale locks교착도, 남은 잠금도 없이A fair queue with cycle detection; claims expire when a session dies.공정한 대기열과 순환 감지. 세션이 끝나면 점유도 자동 해제됩니다.
  • Every verdict explained모든 판단에 근거Who holds what, on which branch — and what's free instead.누가 무엇을 어느 브랜치에서 잡고 있는지, 대신 쓸 수 있는 부분까지.
