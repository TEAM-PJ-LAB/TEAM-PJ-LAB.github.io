The product제품

Interlock

Run many AI coding agents on one codebase — without them overwriting each other. 여러 AI 코딩 에이전트가 하나의 코드베이스에서, 서로의 작업을 덮어쓰지 않게.

Claude Code, Codex and Cursor are good enough to run in parallel — but they don't notice each other. Interlock is the signal box for your agents: it knows what every agent is changing, never lets two changes collide, and explains every decision. Claude Code, Codex, Cursor는 이제 동시에 돌릴 만큼 뛰어나지만, 서로를 알아채지 못합니다. Interlock은 에이전트들의 신호소입니다. 누가 어떤 코드를 바꾸는지 알고, 두 변경이 부딪히지 않게 막으며, 모든 판단의 근거를 보여줍니다.

Experiment E4실험 E4

On 5,352 real commit pairs, file locking blocked 3,535 edits that git merges cleanly. Interlock blocked none of them. 실제 커밋 5,352쌍에서 파일 잠금은 git이 문제없이 합치는 편집 3,535건을 막았습니다. Interlock은 그중 한 건도 막지 않았습니다.

The commit histories of httpx, click, requests, zod and ky, replayed as two agents starting at the same time. Of the 1,817 pairs counted as conflicts, it let through only 2. Interlock V3.0.0, run on 2026-10-18. httpx, click, requests, zod, ky의 커밋 기록을 두 에이전트가 동시에 시작한 상황으로 재현했습니다. 충돌로 분류한 1,817쌍 중 놓친 것은 2쌍입니다. Interlock V3.0.0, 2026-10-18 실행.

Experiment E1실험 E1

A teammate's agent declared a signature change. Without Interlock, the other agent wrote the old call 20 of 20 times. With it, every call fit the new one. 동료 에이전트가 시그니처 변경을 선언했습니다. Interlock이 없으면 다른 에이전트는 20번 모두 옛 방식으로 호출했고, Interlock이 있으면 모든 호출이 새 시그니처에 맞았습니다.

Real Claude Code sessions on four tasks in Python and TypeScript, five runs each. The six runs that were refused all fixed the call themselves and finished. Interlock V3.0.0, run on 2026-10-18. Python·TypeScript 작업 4종, 작업마다 5회씩 실제 Claude Code 세션으로 돌렸습니다. 거부된 6번도 모두 스스로 호출을 고쳐 작업을 끝냈습니다. Interlock V3.0.0, 2026-10-18 실행.
