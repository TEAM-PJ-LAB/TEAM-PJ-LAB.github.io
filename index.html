Our technology핵심 기술

What we know how to build.우리가 만들 수 있는 것.

AI agent toolingAI 에이전트 도구

Hooks and an MCP server for Claude Code, Codex and Cursor, so a tool works next to the agents teams already use.Claude Code · Codex · Cursor와 함께 쓰는 훅과 MCP 서버. 팀이 이미 쓰는 에이전트 옆에 붙습니다.

Code analysis코드 분석

Function-level analysis of source code to know what a change touches, and which callers a changed signature affects.소스 코드를 함수 단위로 분석해, 변경이 무엇을 건드리는지와 시그니처가 바뀌면 어떤 호출이 영향받는지 파악합니다.

Workflow automation워크플로 자동화

git pre-commit hooks and a GitHub App merge check, so rules are enforced without asking people to remember them.git pre-commit 훅과 GitHub App 머지 체크로, 사람이 기억하지 않아도 규칙이 지켜지게 합니다.

Performance성능

Hook decisions in about 3 to 6 ms on a 2,000-line file, so enforcement does not slow agents down.2,000줄 파일에서 훅 판단이 약 3~6 ms로, 강제 적용이 에이전트를 느리게 하지 않습니다.

Research & development연구개발

We test before we ask for trust.믿어 달라고 하기 전에 먼저 검증합니다.

Experiments run on real code and real Claude Code sessions, each published with its method, limits and raw data.실제 코드와 실제 Claude Code 세션으로 실험하고, 방법 · 한계 · 원자료를 모두 공개합니다.

Two agents starting at once on the real histories of httpx, click, requests, zod and ky.httpx, click, requests, zod, ky의 실제 커밋 기록에서 두 에이전트가 동시에 시작한 상황을 재현.

Live agent sessions실제 에이전트 세션
