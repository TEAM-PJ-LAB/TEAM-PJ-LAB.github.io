Interlock

Lets a team run several AI coding agents on one repository at once. It tracks which function each agent is changing and holds the edits that would collide, at the edit, the commit and the merge.한 저장소에서 여러 AI 코딩 에이전트를 동시에 돌릴 수 있게 합니다. 에이전트마다 어떤 함수를 바꾸는지 추적하고, 부딪힐 편집은 편집 · 커밋 · 머지 단계에서 잡아 둡니다.

CISS

CISS (Code Information Sharing Service) records who first designed the algorithms in public code and how later ones were derived from them, with a source for every link: 274 algorithms, 465 contributors and 190 derivations, with search, a lineage map and a repository scan that lists the originators of the algorithms a project uses.CISS(Code Information Sharing Service)는 공개 코드 속 알고리즘을 누가 처음 설계했고 이후 무엇이 어떻게 파생됐는지, 연결마다 출처를 붙여 기록합니다. 알고리즘 274개 · 기여자 465명 · 파생 관계 190개를 검색 · 계보 지도로 보여 주고, 저장소를 분석해 쓰인 알고리즘의 원작자 목록을 만들어 줍니다.
